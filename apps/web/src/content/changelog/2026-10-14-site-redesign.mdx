wuup.in has a new design. The site now explains what wuup does with concrete limits instead of slogans, and it collects everything you need to evaluate and set up wuup in one place: docs, guides, free tools and this changelog.

## What's new on the site

- **Docs**: step-by-step setup for [MongoDB](/docs/connect-mongodb), [Google Sheets](/docs/connect-google-sheets) and [documents](/docs/upload-documents), plus [bring your own key](/docs/byok-setup), an [FAQ](/docs/faq) and [troubleshooting](/docs/troubleshooting).
- **Guides**: practical articles such as [MongoDB aggregation pipeline examples](/guides/mongodb-aggregation-pipeline-examples) and [how to create a MongoDB read-only user](/guides/mongodb-read-only-user), with code you can run.
- **Free tools**: generate a MongoDB query or aggregation from a question, explain a pipeline, convert SQL to MongoDB, or infer a schema from JSON, right in the browser. Start at the [MongoDB query generator](/tools/mongodb-query-generator).
- **Security page** with the exact limits the read-only guard enforces.
- **Changelog**: release notes written from the actual commit history.

## In the app

The app is being moved onto the same design system, with a clearer data screen and settings. Those changes will get their own entry when they ship.
