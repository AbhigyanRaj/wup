You can now upload documents and ask questions about them. Each account gets a private knowledge base: wuup extracts the text from a PDF or TXT file, splits it into overlapping passages, embeds them with Google's Gemini embedding model, and searches them when a question needs them. Answers cite the passages they used with numbers that point back to the file and page.

## What shipped

- **Upload** PDF and TXT files from the app. Files are processed in memory and never written to disk.
- **Background indexing**: the upload returns at once and the document moves from pending to indexed while you keep working.
- **Retrieval with citations**: the most relevant passages are added to the answer's context, and each claim that comes from them carries a numbered citation.
- **Guard rails**: a file size cap, per-account limits on documents and passages, duplicate detection by file fingerprint, and an upload rate limit.
- **Delete** removes a document and every passage indexed from it.
