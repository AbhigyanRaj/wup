Some questions need context that is not in your database, such as a public benchmark, a holiday calendar or a competitor's published price. wuup can now search the web for those. Web search is optional and off by default: turn it on for a question and the model can call a search tool, read the top results and cite them next to your own sources.

## How it works

- The model decides when a search would help and sends a short query. Only the query text leaves wuup, not your data.
- wuup reads the top results (title, link and snippet) and passes them to the model as sources.
- Web sources get numbered citations, so you can tell them apart from database rows and document passages.
